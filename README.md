# Gestion Financière Afrique

Application mobile de gestion financière personnelle pensée pour l'Afrique francophone.

## Vision

Une application offline-first, avec stockage local des données financières, profils adaptatifs et outils de planification budgétaire.

## Stack prévue

- React Native
- Expo
- TypeScript
- Expo Router
- SQLite local

## État du projet

Initialisation du dépôt. Le cahier des charges fonctionnel et technique sert de référence pour les prochaines étapes.
